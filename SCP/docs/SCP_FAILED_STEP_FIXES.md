The [functional rehearsal](SCP_FUNCTIONAL_DEMO.md) preserves these checks and continues collecting evidence in subsequent modules after a module fails. It does not silently remove failing tests, alter source responses, substitute expected values or create records to populate empty reports.

The historical Enterprise flow now collects every numeric mismatch as a failing soft assertion before continuing to CSV download/content validation. A dash still fails against a numeric source value; the case remains Failed. Existing callers retain the original hard-assertion behavior. This allows the report to show the rest of the functional flow without suppressing the defect.

## Application changes required

The paths below are filenames exposed by the deployed client, not local application files available for editing.

1. In `SubContractorIssues.tsx`, include the subcontractor name in the search predicate while retaining every matching array record. Keep project search available as appropriate. Do not use a name-keyed map to deduplicate records.
2. In the grouped renderer in `AnalyticsTable.tsx`, render Over-Deliveries for every issue row and include its subtotal. Preserve the eight-column header/data alignment.
3. Define whether clicking Subcontractor sorts the group names. Currently only records inside each group are sorted, so this header cannot reorder the groups.
4. Replace the empty export callback with a real export of the applicable filtered record population, all required columns and selected date scope. Preserve repeated names and identical-record multiplicity.
5. Pass Task Chart dates to ageing as well as the other chart endpoints. Reconcile chart population/status counts with the qualifying source records; inspect backend grouping and ownership/date predicates rather than assuming a specific cause.
6. Resolve zero-versus-unavailable rendering explicitly in Enterprise numeric columns. If zero is numeric, avoid a falsy-value fallback that replaces it with a dash. Document any alternative display contract.
7. Set Inventory calendar defaults to two calendar months before and one calendar month after today in the configured timezone, with month-end clamping.
8. Correct the invalid SSO chooser JavaScript. Authentication runtime errors must remain part of the quality gate.

These changes need the application owner and a new deployed build. The local automation changes alone cannot implement them.
